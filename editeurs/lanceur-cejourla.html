CE JOUR LÀ
Lien Drive ou vidéo depuis l'appareil : choisis la source par jour. Style Fixe : le premier plan réel de la vidéo sert d'intro (titre animé, champ TITRE du brouillon avec mots-clés entre **étoiles**), le reste devient le corps (champ CORPS). Style Karaoké : pas de titre séparé, cartons plein écran dès le début, source = champ CORPS (karaoké) du brouillon — pas le CORPS classique. Chaque jour utilise le brouillon Gmail « POST DU JOUR — sa date ».

Ce qui se passe ensuite
  1. Lancer le montage ouvre un brouillon email pré-rempli dans ta messagerie (ou, si au moins une vidéo vient de l'appareil et que ton navigateur le permet, le menu de partage natif avec les vidéos déjà jointes) — vérifie et envoie-le (ou laisse-le en brouillon, les deux fonctionnent).
  2. Une Routine horaire côté Claude Code cherche un email/brouillon « LANCER REEL » non traité — pièce jointe vidéo ou lien Drive, un seul jour ou plusieurs listés dans le même email, tout est pris en charge.
  3. Si l'email liste plusieurs jours (JOUR 1, JOUR 2…), chacun est traité comme un reel séparé dans la même passe : téléchargement de la vidéo, montage dans le style choisi pour ce jour-là (Fixe : premier plan réel = intro titre animé, reste = corps ; Karaoké : pas d'intro séparée, le corps couvre tout le reel) + CTA de fin selon la recette figée du CLAUDE.md, rendu, vérification par extraction de frames.
  4. Commit/push de chaque fichier final sur la branche ce-jour-là — tu reçois une notification listant le chemin de chaque reel produit.
  5. L'email déclencheur est marqué traité (tous les jours qu'il contenait) pour ne pas être relancé deux fois.
⏱ La vérification se fait une fois par heure (limite technique des Routines programmées) — pas de lancement instantané. Pour un montage immédiat, demande-le directement dans le chat Claude Code comme d'habitude.
