ÉPHÉMÉRIDE
Demande une éphéméride (liste d'options « Ce jour-là » à valider par ✅) pour une date précise, ou pour plusieurs jours consécutifs d'un coup — un seul email, un seul brouillon d'options en retour avec une section par jour à valider indépendamment.

PLUSIEURS JOURS

Ce qui se passe ensuite
  1. Lancer l'éphéméride ouvre un brouillon email pré-rempli dans ta messagerie — vérifie et envoie-le (ou laisse-le en brouillon, les deux fonctionnent).
  2. Une Routine horaire côté Claude Code cherche un email/brouillon « LANCER ÉPHÉMÉRIDE » non traité.
  3. Si elle en trouve un : recherche web des événements foot pour chaque date demandée, vérification par 3 sources indépendantes, puis production d'un brouillon « ⚽ Éphéméride foot une·deux » — une section « JOUR N » par date si plusieurs jours, options numérotées à valider par ✅ dans chacune.
  4. Tu valides ensuite normalement (✅ devant l'option choisie, par jour) — la routine quotidienne « Post du jour » prend le relais pour produire un « POST DU JOUR » par date validée.
  5. L'email déclencheur est marqué traité pour ne pas être relancé deux fois.
⏱ La vérification se fait une fois par heure — pas de génération instantanée. Pour une éphéméride immédiate, demande-la directement dans le chat Claude Code comme d'habitude.
